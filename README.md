### 🧠 SYNAPSEAI LAUNCHES TO PUBLIC — [LIVE ↗](https://synapseai-front.vercel.app) · [SOURCE ↗](https://github.com/HarshMishra2803/synapseai)

> *"A full-stack SaaS Second Brain that actually works"*

Developer builds **10-endpoint REST API** in Express 5 + TypeScript, ships
JWT-secured knowledge vault letting users store YouTube videos, tweets,
articles & notes — all tagged, pinned, and searchable.

**Groq LLaMA 3.1** powers one-click AI summarization. If Groq goes down,
system falls back to Gemini, then to local extraction — **100% uptime on
the feature, zero excuses.**

Public brain-sharing ships via **crypto-generated unique hashes.**
Deployed across Vercel + Render + MongoDB Atlas. Bundle: 102KB gzipped.

`React 18` · `TypeScript` · `Node.js` · `Express 5` · `MongoDB` · `JWT` · `Groq AI`

### 🛡️ KAVACH GOES LIVE — FIGHTS FRAUD WITH AI — [LIVE ↗](https://kavach-scamshield.onrender.com) · [SOURCE ↗](https://github.com/HarshMishra2803/Kavach)

> *"Real-time scam detection built for India"*

In a move described by peers as "actually useful," Mishra releases a
**full-stack threat detection platform** that scans URLs, UPI IDs, and
suspicious messages through **Google Gemini AI.**

Zero polling. Real-time scam heatmap rendered via **Firestore onSnapshot
+ React Leaflet** — live geographic incident tracking across Indian cities.

Emergency SOS module generates **AI-drafted legal complaints** for the
National Cyber Crime Portal (Helpline: 1930). API keys never touch the
client — server-side proxying enforced throughout.

`React 19` · `Node.js` · `Firebase Auth` · `Gemini AI` · `Leaflet.js` · `OAuth`
